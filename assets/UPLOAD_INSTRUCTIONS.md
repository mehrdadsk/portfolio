# Complete the About me video integration

The portfolio About me page and CSS have already been updated in GitHub.

Upload these two media files to your GitHub repository, inside the **assets/videos/** folder:

- MK_life_story_v3.mp4
- MK_life_story_poster.jpg

Repository: https://github.com/mehrdadsk/portfolio
Direct folder: https://github.com/mehrdadsk/portfolio/tree/main/assets/videos

Steps:
1. Open the direct folder above and sign into GitHub.
2. Select **Add file > Upload files**.
3. Open this ZIP locally, navigate to **assets/videos/**, and drag both the MP4 and JPG into GitHub's upload area.
4. Click **Commit changes** on branch **main**.
5. Once GitHub Pages has deployed, visit https://mehrdadsk.github.io/portfolio/about.html and refresh if necessary.

The page will display the embedded video only once the MP4 is uploaded successfully, avoiding a broken media panel while the asset is missing. The film is click-to-play, with native playback controls and responsive widescreen styling. No autoplay.
